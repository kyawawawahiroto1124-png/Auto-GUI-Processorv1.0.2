# **🖱️ 自動操作プロセッサ (Auto GUI Processor) v1.0.2**

Windows 95/98風のレトロな外観を持つ、直感的なデスクトップ自動化ツールです。

複雑なコードを書くことなく、マウス操作（クリック、ドラッグ）やスクリーンショット撮影をシーケンスとして記録し、自動実行・ループ再生できます。

## **📺 デモ・スクリーンショット**

## **✨ 主な機能**

* **レトロ・ビジュアル**: 90年代のOSを彷彿とさせるクラシックなUIデザイン。  
* **簡単レコーディング**: 画面を直接ドラッグして座標を指定する直感的な操作。  
* **高度なループ制御**:  
  * **回数指定**: 指定した回数だけ実行して停止。  
  * **無限ループ**: 手動で停止するまで連続実行。  
  * **タイマー実行**: 指定した時間（分単位）が経過するまで実行。  
* **プロジェクト管理**: 作成した自動化フローを JSON 形式で保存・読み込み可能。  
* **キャプチャ機能**: 指定範囲のスクリーンショットを自動で保存（連番保存対応）。

## **🚀 クイックスタート**

### **1\. 準備 (依存ライブラリの導入)**

以下のコマンドを実行して、必要なライブラリをインストールしてください。

pip install pyautogui pillow

### **2\. インストールと起動**

リポジトリをクローンまたはダウンロードし、インストーラーを実行します。

python installer\_gui.py

※ インストーラーを完了すると、自動的にメインアプリケーションが起動します。

## **📂 ファイル構成**

* auto\_gui\_app.py: アプリケーション本体（ロジックとメインUI）。  
* installer\_gui.py: ウィザード形式のセットアップ・ランチャー。  
* setup.py: パッケージ管理・インストール用スクリプト。  
* README.md: 本ドキュメント。  
* LICENSE: MITライセンス規定。

## **⚠️ 使用上の注意**

* **安全装置**: PyAutoGUIのセーフガードが有効です。マウスを画面の四隅のいずれかに素早く移動させると、実行を強制停止できます。  
* **環境制限**: 本ツールはGUIが必要です。SSH経由やディスプレイのないヘッドレスサーバー、Dockerコンテナ内では動作しません。  
* **管理者権限**: 操作対象のアプリによっては、本ツールを「管理者として実行」する必要があります。
